## 2. 4대보험 (근로자 월 부담)

입력: `T`(월 과세급여), 기준일 `d`, 사업장 규모, 산재율.

```
국민연금 기준소득월액  B_np = clamp(⌊T⌋₁₀₀₀, min(d), max(d))        (T = 0 이면 0)
  근로자 국민연금      NP_w = ⌊B_np × 4.75%⌋₁₀
  사업주 국민연금      NP_e = NP_w

건강보험료(전체)       H   = clamp(T × 7.19%, 20,160, 9,183,480)
  근로자 건강보험      HI_w = ⌊H / 2⌋₁₀           ( = ⌊T×3.595%⌋₁₀ , 상·하한 범위 안)
  사업주 건강보험      HI_e = HI_w
장기요양보험
  근로자               LTC_w = ⌊HI_w × (0.9448 / 7.19)⌋₁₀
  사업주               LTC_e = LTC_w

고용보험
  근로자               EI_w = ⌊T × 0.9%⌋₁₀
  사업주               EI_e = ⌊T × (0.9% + 안정·직능요율)⌋₁₀
산재보험(사업주만)     WC_e = ⌊T × 산재율⌋₁₀
```
근로자 합계 `D_ins = NP_w + HI_w + LTC_w + EI_w`, 사업주 합계 `E_ins = NP_e + HI_e + LTC_e + EI_e + WC_e`.

**기준 예시 (검산용 고정 벡터)**
| 케이스 | 기대값 | 근거 |
|---|---|---|
| T = 3,000,000, 기준일 2026-10-10 | NP 142,500 · HI 107,850 · LTC 14,170 · EI 27,000 · **근로자 합 291,520** | 요율 곱셈, 공개 사례(291,520원)와 일치 |
| T = 2,000,000 | HI 71,900 · LTC 9,440 · 합 81,340 | 4대보험 모의계산 공식 예시(S3) |
| T = 3,000,000, 150인 미만, 산재 1.47% | 사업주: NP 142,500 · HI 107,850 · LTC 14,170 · EI 34,500 · WC 44,100 → **합 343,120** | 위 식 |
| T = 7,000,000, 기준일 2026-10-10 | B_np = 6,590,000 (상한) → NP_w 313,020 | S6 |
| T = 7,000,000, 기준일 2026-03-01 | B_np = 6,370,000 → NP_w 302,570 | S6 (7/1 이전 상한) |
| T = 300,000 | B_np = 410,000 (하한) → NP_w 19,470 | S6 |

## 3. 근로소득세 (월 원천징수, 간이세액표)

입력: `T`(월 과세급여, 원), 공제대상가족 수 `F`(본인 포함, 1~), 8~20세 자녀 수 `C`.

```
k = T / 1,000   (천원)
if k < 770:                        tax = 0
elif 770 ≤ k < 10,000:             tax = table[band(k)][F]        (구간 [이상, 미만), F 는 1~11)
elif k = 10,000:                   tax = at10000[F]
else (k > 10,000):                 tax = ⌊ at10000[F] + add + (k−threshold)×1000×factor×rate + plus ⌋₁₀    ← 별표2 말미 계산식 (JSON `over10000`)
F > 11:                            tax = tax(11) − (tax(10) − tax(11)) × (F − 11)        (최소 0)
자녀 공제:                          tax = max(0, tax − childCredit(C))
    childCredit(0)=0, (1)=20,830, (2)=45,830, (n≥3)=45,830 + 33,330×(n−2)
지방소득세 = ⌊tax × 10%⌋₁₀
```
- 구간 폭: 770~1,500천원 5천원, 이후 10천원, 이후 20천원 (원문 그대로).
- **검증 벡터(원문)**: T=3,010,000, F=1 → 74,350원 / F=2 → 56,850 / F=3 → 31,940. T=2,500,000, F=1 → 35,600. T=5,000,000, F=1 → 335,470.
- 10,000천원 초과 구간(예 T=12,000,000, F=1): `1,507,400 + (2,000천원×1000 × 0.98 × 35%) + 25,000 = 1,507,400 + 686,000 + 25,000 = 2,218,400`.
- 이 표는 월 원천징수액이며 **연말정산 결과(환급/추가납부)와 다르다.** 화면에 명시.

## 4. 연봉 계산기

```
월 총지급액 M = ⌊연봉 / 12⌋          (퇴직금 포함: ⌊연봉 / 13⌋)
월 비과세 N   = min(입력, M)
T = M − N
공제 = D_ins(T) + 소득세(T,F,C) + 지방소득세
월 실수령 = M − 공제
연 실수령 = 월 실수령 × 12     (퇴직금 포함이면 12회분만)
실효 공제율 = 공제 / M
```

### 4.1 역산 (희망 월 실수령 → 필요 연봉)
`net(연봉)`은 연봉에 대해 단조 증가이므로 이분 탐색.
```
lo = 10,000,000 , hi = 2,000,000,000 (1만원 단위)
while hi − lo > 10,000: mid = ⌊(lo+hi)/2⌋ 만원단위 ; if net(mid) ≥ 목표 → hi=mid else lo=mid
결과 = hi  (net(hi) ≥ 목표를 만족하는 최소 1만원 단위 연봉)
```
> 간이세액표가 구간 계단형이라 소폭 불연속이 있어 "만족하는 최소 연봉"으로 정의한다 (같은 실수령을 만드는 연봉이 여럿이면 가장 낮은 값).

## 5. 급여 계산기

**월급제**
```
통상시급 W_o = ⌊(기본급 + 통상임금 포함 수당) / 209⌋
연장수당   = ⌊W_o × 1.5 × 연장시간⌋          (연장분 100% + 가산 50%)  ※ 월급에 8시간분이 포함되므로 별도 지급분은 '가산 포함 1.5배'로 계산
야간가산   = ⌊W_o × 0.5 × 야간시간⌋          (22~06시, 다른 가산과 중복 가능)
휴일수당   = ⌊W_o × 1.5 × 휴일(≤8h)⌋ + ⌊W_o × 2.0 × 휴일(8h 초과)⌋
총지급 = 기본급 + 수당합 + 연장/야간/휴일 + 상여
T = 총지급 − 비과세   → §2, §3 적용
```
**시급제**
```
주휴시간(주) h_j = (h ≥ 15) ? min(h,40)/40 × 8 : 0       (h = 주 소정근로시간)
월 소정근로시간 = round(h × 365/7/12) ,  월 주휴시간 = round(h_j × 365/7/12)
기본급 = 시급 × 월 소정근로시간 ,  주휴수당 = 시급 × 월 주휴시간
월 총액 = 기본급 + 주휴수당   (예: h=40 → 174 + 35 = 209시간)
최저임금 충족 = 시급 ≥ 10,320
```
공제 방식 2택: 4대보험+세금(§2·§3 적용, 단 주 15시간 미만은 고용보험·국민연금 가입 제외 안내) / 없음. 3.3% 원천징수는 프리랜서 계산기(§6)에서만 다룬다 (옛 링크의 `deduction=tax33` 은 4대보험+세금으로 열린다).

## 6. 프리랜서

### 6.1 3.3% 원천징수
```
소득세 R = (gross × 3%) 의 원 미만 절사 ,  R < 1,000 이면 R = 0 (소액부징수)
지방소득세 L = ⌊R × 10%⌋ (원 미만 절사) ,  R = 0 이면 0
실수령 = gross − R − L
```
역산(실수령 → 세전): `g = ⌈net / 0.967⌉` 에서 시작해 `forward(g−1).net ≥ net` 인 동안 1원씩 낮춘다 → 실수령 이상을 만드는 최소 세전액.
예: gross 1,000,000 → R 30,000, L 3,000, 실수령 967,000.

**고용보험 공제 (선택, 입력 `eiRate`)** — 예술인·노무제공자(특수형태근로종사자)에게 고용보험이 적용되면 지급처가 세전 금액에서 함께 뗀다.
```
고용보험 E = ⌊gross × eiRate⌋   (eiRate 기본 0 = 공제 안 함)
실수령 = gross − R − L − E          예) 1,000,000 − 30,000 − 3,000 − 9,000(0.9%) = 958,000
역산: keep = 1 − 3%×(1+10%) − eiRate 로 같은 방식
```
- 법정 본인 부담 = 고용보험료율 1.6% × ½ = **0.8%** (보험료징수법 시행령 제56조의5·제56조의6, 시행 2025.12.23). 사업주가 나머지 0.8%를 부담한다. 일반 근로자 본인 부담(0.9%)과 다르다 — 지급처가 0.9%를 떼면 정산서의 값을 그대로 입력한다.
- 모든 프리랜서에게 적용되는 것이 아니다: 적용 직종(보험설계사·택배기사 등)·월 보수 80만원 이상 등 조건이 있고, 상한·기준보수(하한)는 매년 고시된다. 이 계산기는 상·하한을 반영하지 않는다.
- 요율: `data/rates/<연도>/rates.json` 의 `freelancer.employmentInsurance` (`rate`·`workerShare`). 법정 값은 화면 안내와 문구에만 쓰고, 계산에는 사용자가 입력한 `eiRate` 를 쓴다.

### 6.2 5월 종합소득세 정산
```
필요경비   X = ⌊수입 × 단순경비율⌋   (또는 실제 경비 입력)
소득금액   I = 수입 − X
소득공제   Dd = 150만 × 인원(본인 포함) + 연금보험료공제(국민연금 납부액) + 기타공제
과세표준   TB = max(0, I − Dd)
산출세액   S  = ⌊TB × r − q⌋   (제55조 구간별 세율 r, 누진공제 q — rates.json brackets)
세액공제   Cr = 자녀세액공제(C) + 표준세액공제 70,000
결정세액   P  = max(0, S − Cr)
지방소득세  PL = ⌊P × 10%⌋₁₀
기납부     A  = ⌊수입 × 3%⌋   ,  AL = ⌊A × 10%⌋
정산액     = (P − A) + (PL − AL)      → 양수: 추가 납부 / 음수: 환급
```
누진공제 q: 1,400만 이하 0 · 5,000만 이하 126만 · 8,800만 이하 576만 · 1.5억 이하 1,544만 · 3억 이하 1,994만 · 5억 이하 2,594만 · 10억 이하 3,594만 · 초과 6,594만.
(제55조는 "84만원 + 1,400만원 초과분×15%" 형태이므로 `TB×15% − 126만`과 같다. 다른 구간도 같은 방식으로 환산.)
검증: TB 50,000,000 → 15% − 126만 = 624만 = 제55조 "5,000만원 초과" 구간의 기준액 624만 ✓. TB 88,000,000 → 24% − 576만 = 1,536만 = "8,800만원 초과" 기준액 1,536만 ✓.

### 6.3 지역가입자 건강보험·국민연금 추정
```
월 소득월액 m = I / 12                       (프리랜서 사업소득은 소득금액의 100% 반영)
건강보험(월)  = clamp(⌊m×7.19% + 재산점수×211.5⌋₁₀, 20,160, 4,591,740)
장기요양(월)  = ⌊건강보험 × (0.9448/7.19)⌋₁₀
국민연금(월)  = ⌊clamp(⌊m⌋₁₀₀₀, 410,000, 6,590,000) × 9.5%⌋₁₀      (전액 본인 부담, 18~59세·납부예외 가능)
```
**월 실수령 추정 (탭 C)**
```
연 부담 = P + PL + 12 × (건강보험 + 장기요양 + 국민연금) + 실제 지출 경비
월 실수령 = ⌊(연 수입 − 연 부담) / 12⌋
```
단순경비율로 인정받은 필요경비 `X`는 **세법상 경비일 뿐 실제 지출이 아니므로** 실수령 계산에서 빼지 않는다. 실제로 지출한 경비(장비·외주비 등)는 "실제 지출 경비"로 따로 입력하며 기본값은 0이다.
국민연금은 납부액이 소득공제(연금보험료공제)로 세금을 줄이므로, 탭 C는 `Dd`에 12×국민연금을 넣어 §6.2를 다시 계산한 `P`, `PL`을 쓴다.

## 7. 반올림·표시 규칙
- 계산 중간값은 원 단위 정수(소수 금지). 모든 곱셈은 **정수 연산 또는 `Math.floor`** 로 처리, 부동소수 오차 방지를 위해 요율을 만분율 정수(예 7.19% = 719/10000)로 곱한다.
- 화면 금액은 `ko-KR` 천 단위 콤마 + "원". 퍼센트는 소수 1~2자리.

## 10. 연말정산 (`/yearend`) — 2026년 귀속

법령 숫자는 모두 `data/rates/2026/rates.json` 의 `yearend` 에 있다(2027 세트는 2026 을 상속). 출처: S10(소득세법 제47·50·51·51의3·52·55·59~59의4·61·137조), S11(조세특례제한법 제126조의2·제132조의2·제87조·제95조의2·제58조), S12(조특법 시행령 제121조의2). 모두 법제처 원문에서 확인했고 `verified.rules=true`, 단수·추정은 U11~U13.
코드: `src/core/yearend.ts`(한 사람 계산), `src/core/yearend-couple.ts`(부부 배분), `src/core/yearend-input.ts`(입력 해석). 금액은 원 정수, 곱셈은 `pm(x, rate) = mulPpm(x, ppm(rate))`.

### 10.1 단계 (한 사람)
1. **총급여** S = 연 총지급 − 비과세.
2. **근로소득공제**(제47조) → **근로소득금액** L = S − 공제.
3. **소득공제**: 인적공제(본인+기본공제 대상 가족) × 150만원, 70세 이상 직계존속 +100만원(제51조) · 국민연금(제51조의3) · 건강·장기요양·고용보험료(제52조, 전액) · **카드 등 + 주택청약** 은 종합한도 `comprehensiveCap`(2,500만원)까지(조특법 제132조의2).
4. **과세표준** = max(0, L − 소득공제) → 기본세율표(`incomeTax.brackets`)로 **산출세액**.
5. **세액공제**: 근로소득세액공제(55%/30% + 총급여별 한도, 제59조) · 자녀(8세 이상, 제59조의2) · 출산·입양 · 연금계좌(제59조의3) · 특별세액공제(보험료·의료비·교육비·기부금, 제59조의4) 와 월세(조특법 제95조의2) · **표준세액공제 13만원**과 중 큰 쪽(월세를 받으면 표준 불가) · 고향사랑 기부금(조특법 제58조). 합계는 산출세액을 넘지 못한다(제61조).
6. **결정세액** = 산출세액 − 세액공제. **지방소득세** = 결정세액의 10%, 10원 미만 절사.
7. **정산액** = (결정세액 + 지방소득세) − (이미 낸 소득세 + 지방소득세). 음수면 환급.

### 10.2 가족 판정 (귀속연도 Y, 출생연도 b, 나이 = Y − b)
- 기본공제: 배우자(소득요건), 직계비속 나이 ≤ 20, 직계존속 나이 ≥ 60. 소득요건은 사용자가 "연 소득 100만원 초과"를 체크하면 제외.
- 자녀세액공제: 기본공제 대상 자녀 중 나이 ≥ 8. 의료비 특례(한도 없음): 본인·자녀 나이 ≤ 6·부모 나이 ≥ 65, 그 밖의 가족과 배우자 의료비는 700만원 한도.

### 10.3 카드 등 사용액 공제 (조특법 제126조의2, 2026.1.1 시행분)
최저사용금액 = S × 25%. 사용액을 신용카드 → 체크·현금영수증·(총급여 7천만원 이하면 문화체육) → 전통시장·대중교통 순으로 최저사용금액에 먼저 채운다(공제율이 낮은 것부터 소진). 초과분 × 공제율(신용 15%·체크 30%·시장·교통 40%·문화체육 30%) = 공제, 기본 한도(총급여 7천 이하 300만 / 초과 250만)를 넘는 부분은 추가 한도(전통시장·대중교통·문화체육, 300만/200만)까지, 20세 이하 자녀 수에 따른 기본 한도 가산(S12). 가족 카드 사용액은 소득요건 충족 가족 것을 합산.

### 10.4 4대보험·기납부세액 추정 (U12·U13)
직접 입력이 없으면 `annualInsurance`(월 보험료×12; 3월~9월은 `${Y}-03-01`, 10월~은 `${Y}-10-01` 요율 세트)와 `withholdingTax`(간이세액표×12)로 추정하고, 화면에 "추정" 배지·안내를 띄운다.

### 10.5 부부 공제 배분 비교
부양가족 n 명(≤6)을 각각 나/배우자에게 배정하는 2ⁿ 가지 × 공동 카드 지출을 10% 단위로 나누는 11 가지(공동 지출이 없으면 1 가지)를 **모두 계산**해 두 사람의 (결정세액 + 지방소득세) 합이 가장 작은 안을 고른다(전수 탐색이라 최적, 최대 704 회·수십 ms). 가족마다 "반대로 옮기면 +얼마"를 한 명씩 뒤집어 계산해 보여 준다. 가정: 가족의 의료비·교육비·카드는 공제받는 쪽이 실제로 쓴 것으로 본다, 배우자는 서로 기본공제 대상이 아니다(소득요건 충족 시 서로 공제 가능하지만 각자 본인공제), 한 사람을 양쪽이 동시에 공제받을 수 없다.

### 10.5b 프리랜서(사업소득) 배우자 — 부부 탭의 "소득 유형"
부부 중 한쪽(또는 양쪽)이 프리랜서면 그 사람은 **5월 종합소득세**로 계산한다 (`evaluateFreelancer`). 근거: 소득세법 제51조(인적공제)·제51조의3(연금보험료공제, "종합소득이 있는 거주자")·제55조(세율)·제59조의2(자녀세액공제, "종합소득이 있는 거주자")·제59조의3(연금계좌세액공제, 종합소득금액 4,500만원 이하 15% / 초과 12%)·제59조의4 제9항 제2호(근로소득이 없는 종합소득자 표준세액공제 7만원). 법제처 현행 원문(시행 2026.1.1~)에서 확인.
1. 수입금액 − 필요경비(단순경비율 × 수입 또는 실제 경비) = 사업소득금액. 2. 인적공제(본인+기본공제 대상 가족, 경로우대 포함) + 국민연금(지역, 직접 입력 없으면 `calcRegional` 로 월 소득 추정 × 12) → 과세표준 → 기본세율. 3. 자녀·출산입양·연금계좌·표준세액공제(7만원). 4. 지방소득세 10%(10원 미만 절사). 5. 기납부세액 = 수입 × 3%(직접 입력 가능).
**받을 수 없는 것**: 근로소득공제·근로소득세액공제, 신용카드 등 소득공제(조특법 제126조의2, "근로소득이 있는 거주자"), 건강보험료 소득공제(제52조, 근로소득자), 보험료·의료비·교육비 특별세액공제(제59조의4 제1~3항, "근로소득이 있는 거주자"), 기부금 세액공제(제59조의4 제4항, "사업소득만 있는 자는 제외"). 그래서 프리랜서 쪽에 배정된 가족의 의료비·교육비·보험료·카드는 계산하지 않고(화면에 안내), 부부 최적화는 이런 지출을 근로자 쪽에 몰아 주는 안을 자연스럽게 고른다. 프리랜서 배우자의 의료비는 근로자가 직접 낸 경우 근로자의 "배우자 의료비"로 공제받을 수 있다(제59조의4 제2항, 기본공제대상자는 나이·소득 제한 없음).
**미반영(화면에 명시)**: 성실사업자 표준세액공제 12만원, 노란우산공제 등 사업자 소득공제, 월세·고향사랑 세액공제, 다른 소득과의 합산. 가정: 사업소득만 있음.
